# IK Path MVP (Blender Addon)

**IK Path MVP** — аддон для Blender (4.x / 5.x LTS), позволяющий анимировать кости и риги с помощью рисования траектории (дуги движения) прямо во вьюпорте.

Выделяете кость-контроллер (например, голову), нажимаете **Draw Path and Bake**, проводите кривую ЛКМ в 3D Viewport — и на отпускании мыши аддон мгновенно запекает анимацию перемещения по этой дуге с физически корректным поведением тела.

---

## Основные режимы работы (Solvers)

### 1. Direct Mode
- Контроллер строго следует нарисованной линии.
- Если у рига настроены эластичные констрейнты (Rigify Stretch-To / IK), шея/конечность естественно тянется за контроллером.
- Подходит для локальной анимации отдельных контроллеров.

### 2. Body Drag (Ragdoll / Rope Slack Model)
Режим утягивания тела за контроллером (эффект «тряпичной куклы» / натянутой верёвки):
- **Unstretched Reach (Натуральный вылет):** Аддон автоматически анализирует деформ-кости (DEF- цепочку) и вычисляет естественную максимальную длину шеи/конечности в распрямленном состоянии.
- **Slack (Задержка движения тела):** Пока нарисованная линия находится в пределах естественной длины (шея просто распрямляется из свернутой позы) — тело (
oot) стоит абсолютно неподвижно.
- **Tension & Drag (Утягивание):** Как только линия уводит голову дальше максимальной длины шеи, натягивается «верёвка», и тело начинает прямолинейно следовать за головой.
- **Limit Stretch:** Предотвращает превращение шеи в бесконечную резину — голова удерживается на максимальном вылете распрямленных костей.
- **Body Lean / Turn (Наклон и поворот тела):** При утягивании тело плавно наклоняется и поворачивается в сторону вектора натяжения, создавая органичное ощущение веса и инерции.
- **Leg Drag & Dangle (Физика ног):** Ноги стоят на полу, пока тело поднимается в пределах длины ног. При отрыве от земли ноги отстают по инерции и вытягиваются назад/вниз с оттянутыми носками (как в полете).
- **Pinned Bones (Фиксация костей):** Возможность зафиксировать любые кости в мировом пространстве (например, приколотить ступни к полу) одной кнопкой.

## Настройки панели (N-Панель -> IK Path MVP)

| Параметр | Описание |
|---|---|
| **Draw Path and Bake** | Интерактивное рисование пути ЛКМ во вьюпорте и автозапекание |
| **Controller** | Активный объект / кость-контроллер (автозахват при выделении) |
| **Solve Mode** | Direct или Body Drag |
| **Body Follow** | Доля избыточного смещения, передаваемая кости 
oot (0.0 — тело стоит, 1.0 — полное следование) |
| **Body Lean** | Наклон/доворот тела в сторону вектора натяжения (0.0 — без наклона, 0.5 — естественный наклон) |
| **Leg Drag & Dangle** | Ноги остаются на полу до предела длины, а в воздухе оттягиваются назад/вниз |
| **Toe Point** | Степень оттягивания носков вниз вдоль ноги при висении в воздухе |
| **Limit Stretch** | Защита от бесконечного растяжения ригифайных костей |
| **Max Reach** | Максимальный вылет в метрах (0.0 — автоопределение по сумме длин деформ-костей) |
| **Pinned Bones** | Pin Selected — зафиксировать выделенные кости в мире; Unpin All — снять замки |
| **Root Bone** | Имя кости-носителя всего тела (по умолчанию автопоиск 
oot, 	orso) |
| **Root Max Translate** | Ограничение максимальной дистанции перемещения 
oot (0 = без ограничений) |
| **Path Mode** | Absolute (по координатам штриха) или Relative (от текущей позы контроллера) |

## Совместимость
- **Blender:** 4.0, 4.1, 4.2, 4.3, 4.4, 5.0, 5.1, 5.2 LTS
- **Rigs:** Rigify (Biped, Quadruped, Bird/Flamingo), базовые кости, кастомные IK/FK сетапы.
- Поддерживает новую систему Action Layers в Blender 4.4+ / 5.x.

---

## Установка
1. Скачайте репозиторий (или папку ik_path_mvp).
2. Запакуйте папку ik_path_mvp в ZIP-архив (или поместите в папку ваших пользовательских аддонов).
3. В Blender: **Edit** -> **Preferences** -> **Add-ons** -> **Install from Disk...** -> выберите архив.
4. Включите галочку **IK Path MVP**.
