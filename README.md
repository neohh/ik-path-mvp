# IK Path MVP (Blender Addon)

**IK Path MVP** — аддон для Blender (4.x / 5.x LTS), позволяющий анимировать кости и риги с помощью рисования траектории (дуги движения) прямо во вьюпорте.

Выделяете кость-контроллер (например, голову), нажимаете **Draw Path and Bake**, проводите кривую ЛКМ в 3D Viewport — и на отпускании мыши аддон мгновенно запекает анимацию перемещения по этой дуге с физически корректным поведением тела.

---

## Основные режимы работы (Solvers)

### 1. Direct Mode
- Контроллер строго следует нарисованной линии.
- Если у рига настроены эластичные констрейнты (Rigify Stretch-To / IK), шея/конечность естественно тянется за контроллером.
- Подходит для локальной анимации отдельных контроллеров.

### 2. Body Drag (Ragdoll / Rope Slack Model)
Режим утягивания тела за контроллером (эффект «тряпичной куклы» / натянутой верёвки):
- **Live Preview & Интерактивное редактирование:** После рисования штриха анимация сразу создаётся на таймлайне, а аддон переходит в режим предпросмотра (`Preview Active`). Вы можете двигать любые ползунки (`Body Follow`, `Body Lean`, `Leg Ground Reach`, `Toe Point`) на **любом кадре таймлайна** (например, просматривая 40-й кадр): анимация пересчитывается без искажений из чистой позы нулевого кадра, а плейхед остаётся на месте. Кнопка **Apply Bake** финализирует результат, а **Cancel** сбрасывает изменения.
- **Гарантия первого кадра (Frame 1 Safe):** Исходная поза персонажа на первом кадре (`frame_start`) строго сохраняется на 100% без рывков и смещений, независимо от того, в какой точке экрана начато рисование мыши.
- **Честный пин костей (Live Constraint-Based Pinning):** Кнопка **Pin Selected** привязывает выделенные кости через констрейнт `COPY_TRANSFORMS` к мировым пустышкам. Даже если вы вручную крутите `root` или бёдра в Pose Mode прямо во вьюпорте, закреплённая голова или шея остаётся неподвижной в мировом пространстве. **Unpin All** аккуратно снимает ограничения.
- **Прямой горизонтальный Root (Zero Pitch/Roll Tilt):** Главная кость `root` всегда остаётся строго прямой и горизонтальной на полу (нулевой наклон/крен вперед или вбок, `rot.x = 0, rot.y = 0`). При регулировке `Body Lean` кость `root` аккуратно поворачивается по горизонтали (yaw вокруг оси Z) в направлении движения, сохраняя ноги на земле. Внутренние кости позвоночника/таза не скручиваются.
- **Unstretched Reach (Натуральный вылет):** Аддон автоматически анализирует деформ-кости (DEF-цепочку) и вычисляет естественную максимальную длину шеи/конечности в распрямленном состоянии.
- **Slack (Задержка движения тела):** Пока нарисованная линия находится в пределах естественной длины (шея просто распрямляется из свернутой позы) — тело (`root`) стоит абсолютно неподвижно и без наклона.
- **Tension & Drag (Утягивание):** Как только линия уводит голову дальше максимальной длины шеи, натягивается «верёвка», и тело начинает следовать за головой.
- **Limit Stretch:** Предотвращает превращение шеи в бесконечную резину — голова удерживается на максимальном вылете распрямленных костей.
- **Body Lean (Горизонтальный доворот):** Доворот тела по курсу натяжения (горизонтальный рыскающий поворот `root`, ползунок от -1.0 до 1.0).
- **Двухфазная физика ног (Two-Phase Leg Drag):**
  - *Фаза 1 (Стойка на земле):* При смещении бёдер ступни остаются прижатыми к полу в исходных точках, а ноги естественно вытягиваются по диагонали (до предела `Leg Ground Reach`).
  - *Фаза 2 (Отрыв и волочение):* При превышении длины или подъёме туловища в воздух ступни плавно отрываются от земли, следуют за бёдрами с естественным отставанием и оттягивают носки назад/вниз (`Toe Point`).

## Настройки панели (N-Панель -> IK Path MVP)

| Элемент / Параметр | Описание |
|---|---|
| **Draw Path and Bake** | Интерактивное рисование пути ЛКМ во вьюпорте и переход в Live Preview |
| **Apply Bake** | Завершить предпросмотр, удалить вспомогательную кривую и запечь ключи |
| **Cancel** | Отменить предпросмотр, удалить кривую и вернуть исходную позу |
| **Controller** | Активный объект / кость-контроллер (автозахват при выделении) |
| **Solve Mode** | `Direct` или `Body Drag` |
| **Body Follow** | Доля избыточного смещения, передаваемая кости `root` (0.0 — тело стоит, 1.0 — полное следование) |
| **Body Lean** | Горизонтальный доворот `root` вокруг Z в сторону вектора натяжения (-1.0 до 1.0, по умолчанию 0.0) |
| **Leg Drag & Dangle** | Двухфазная физика ног: стойка на полу по диагонали -> отрыв и волочение в воздухе |
| **Leg Ground Reach** | Коэффициент диагонального вылета ноги до отрыва ступни от земли (по умолчанию 1.25) |
| **Toe Point** | Степень оттягивания носков вниз вдоль ноги при висении в воздухе |
| **Limit Stretch** | Защита от бесконечного растяжения ригифайных костей |
| **Max Reach** | Максимальный вылет в метрах (0.0 — автоопределение по сумме длин деформ-костей) |
| **Pinned Bones** | `Pin Selected` — зафиксировать в мировом пространстве через констрейнты; `Unpin All` — снять все пины |
| **Root Bone** | Имя кости-носителя всего тела (по умолчанию автопоиск `root`) — строго горизонтальная, без наклонов в землю |
| **Root Max Translate** | Ограничение максимальной дистанции перемещения `root` (0 = без ограничений) |
| **Path Mode** | `Absolute` (по координатам штриха) или `Relative` (от текущей позы контроллера) |

## Совместимость
- **Blender:** 4.0, 4.1, 4.2, 4.3, 4.4, 5.0, 5.1, 5.2 LTS
- **Rigs:** Rigify (Biped, Quadruped, Bird/Flamingo), базовые кости, кастомные IK/FK сетапы.
- Поддерживает новую систему Action Layers в Blender 4.4+ / 5.x.

---

## Установка
1. Скачайте репозиторий (или папку ik_path_mvp).
2. Запакуйте папку ik_path_mvp в ZIP-архив (или поместите в папку ваших пользовательских аддонов).
3. В Blender: **Edit** -> **Preferences** -> **Add-ons** -> **Install from Disk...** -> выберите архив.
4. Включите галочку **IK Path MVP**.
